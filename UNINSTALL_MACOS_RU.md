# Удаление Telegram Search MCP

## Отключить MCP, сохранив свой вход

Завершите Telegram-запросы и выполните:

```sh
bash "$HOME/Applications/TelegramSearchMCP/current/uninstall-macos.command" --clients both
```

Можно указать только `codex` или `gemini`. Скрипт удаляет распознанные подключения
общего пакета и сохраняет резервные копии настроек. Посторонние MCP-записи,
старые установки 0.2/0.3, файлы программы, профиль и Keychain сохраняются.
Перезапустите выбранные клиенты. Общий сервис не останавливается автоматически:
второй подключённый клиент может продолжать им пользоваться.

Если запускаете скрипт из распакованного архива, укажите установленную версию
или её ссылку `current`:

```sh
bash uninstall-macos.command --install-dir "$HOME/Applications/TelegramSearchMCP/current" --clients both
```

Здесь `--install-dir` означает одну установленную версию; у установщика тот же
параметр задаёт корень всех версий. При нестандартном каталоге программы замените
путь на свой. Если использовали `--codex-config` или `--gemini-config`, передайте
те же абсолютные пути скрипту удаления.

## Полностью удалить программу

1. Сначала отключите её от **всех** клиентов командой выше и закройте их старые задачи.
2. Остановите сервис:

   ```sh
   "$HOME/Applications/TelegramSearchMCP/current/tgsearch" service stop
   ```

3. В Finder удалите каталог `~/Applications/TelegramSearchMCP`. Если при установке
   задавали другой `--install-dir`, удалите именно свой каталог программы.

Homebrew, uv, Python и TDLib могут использоваться другими программами — скрипт
их автоматически не удаляет.

## Дополнительно удалить данные и отозвать вход

Эти действия нужны только если вы хотите удалить собственную локальную историю
и завершить авторизацию:

1. В Telegram откройте **Настройки → Устройства** и завершите сессию с названием
   **Shared local read-only Telegram search**. Сверьте устройство и время входа.
2. После остановки сервиса удалите через Finder каталог
   `~/Library/Application Support/TelegramSearchMCPShared`.
3. В приложении macOS **Связка ключей / Keychain Access** найдите service
   `local.unofficial-telegram-search-mcp-shared` и удалите его записи
   `default:api_hash` и `default:database_key`.

Не удаляйте записи других приложений или старые профили, если они ещё нужны.
Не удаляйте `tdlib.lock`, чтобы «исправить» работающую сессию. Отдельная остановка
сервиса закрывает базу без выхода из Telegram; отзыв устройства делается в Telegram.

Если хотите сохранить возможность входа после переустановки, пропустите этот раздел:
удаление только программы сохраняет профиль и Keychain.
